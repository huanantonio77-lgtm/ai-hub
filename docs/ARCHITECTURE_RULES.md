# ARCHITECTURE RULES — arbitrage_bot

**Единый источник правды по архитектурным ограничениям бота.**
Создан: s156 (2026-10-05). Обновляется только при явном решении Куратора.

═══════════════════════════════════════════════════════════════════

## Главный принцип

**Бот работает полностью автономно на железе пользователя (Mac).**
**Ни один торговый запрос не уходит к внешним ИИ-сервисам.**
Все решения о торговле принимает локальный код. Всё — детерминировано.

═══════════════════════════════════════════════════════════════════

## 5 жёстких инвариантов

### R1. Ноль LLM-API в коде бота
Запрещены любые сетевые вызовы к LLM-сервисам из `arbitrage_bot/**`:
OpenAI, Anthropic, HuggingFace, llm7, любые `/v1/chat/completions` и аналоги.
Ни в runtime, ни в тестах, ни в конфигах, ни в CI.

### R2. Ноль ML-моделей в runtime stage 1–2
Stage 1 (scaffold) и stage 2 (paper) работают **только на математике
и правилах**: формулы, if/else, сортировки, арифметика.
Никаких нейросетей, sklearn, LightGBM, transformers в runtime.
ML возможен только на stage 3+ — локально, с отдельным gate-verify.

### R3. Детерминизм
Один и тот же вход → **один и тот же выход**. Никакой случайности,
никаких «модель так решила». Все параметры — из конфига (JSON/YAML),
нигде не спрятаны в облаке или в закрытых API.

### R4. Сеть — только к биржам за данными
Разрешено: получить стакан, тикер, историческую свечу с биржи (REST/WS).
Запрещено: отправить данные на анализ куда-либо, кроме собственного Mac.
Данные — можно. Советы — нельзя.

### R5. Решение о сделке — только на Mac
Все вычисления (PnL, комиссии, риск-лимиты, gate-условия) выполняются
локально. Внешние сервисы не имеют доступа ни к параметрам, ни к решениям.
Вся механика бота — на CPU Mac пользователя.

## Связь с ТЗ и gate-правилами

- **ТЗ §12** («Самообучение и ИИ»): терминология «ИИ» в ТЗ = **локальная ML
  stage 3+**, не LLM-API. Уточнение добавлено в s156.
- **ТЗ §13** («Технологический стек»): стек **уже без LLM-зависимостей**
  (Python, asyncio, httpx, Decimal, Postgres, Redis). Проверено s156.
- **Gate LIVE** (PROJECTS.md): LIVE разрешён только при Автономности ≥98% +
  UNRESOLVED=0 + DRIFT=0 + sign 14/14 + нет P0. R1–R5 — обязательное
  условие для прохождения гейта.

## Как проверяется соблюдение

При каждом патче `arbitrage_bot/**`:
- grep по коду на `openai|anthropic|huggingface|langchain|transformers` → должно быть 0 совпадений.
- grep по коду на `requests.post` к чужим доменам → только биржевые хосты.
- Все решения — детерминированы (idempotency-тесты в CI).
